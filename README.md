# powerbi-healtchare-portafolio
Healtchare dashboard with Power BI


Portafolio de Power BI · Sector Salud

Colección de informes de Power BI centrados en el sector sanitario, pensada para mostrar capacidades de modelado de datos y visualización más allá del uso estándar de la herramienta (gráficos de barras, tablas, KPIs básicos).

⚠️ Todos los datos usados en este portafolio son ficticios. Ningún informe contiene información real de pacientes, hospitales ni personal sanitario. El objetivo es exclusivamente demostrativo.

Sobre mí

Analista de Datos con experiencia en el sector salud público (Hospital Clínic de Barcelona, Hospital Universitari Taulí, Generalitat de Catalunya). Este portafolio recoge proyectos personales desarrollados para explorar y demostrar capacidades avanzadas de Power BI aplicadas a analítica sanitaria.
